# Neuro-sama Soundboard

Welcome to the **Neuro-sama soundboard** I made!
I made this because of my recent Neuro-sama interest (since december 2025) and also because I saved some sounds that Neuro-sama made during streams.

You can try the soundboard [here](https://minhtridotnet.github.io/neuro-sama-soundboard/).

If you have a very old browser (like 2013), try [this](https://minhtridotnet.github.io/neuro-sama-soundboard/legacy.html) instead.

Currently there isn't much sounds yet, and I'm going to find more in the future.

---
There are a total of 16 sound effects as of 08/06/2026

All of these sounds have its background noises removed using Ultimate Vocal Remover (UVR) app ran locally in my PC, specifically using the mel-band-roformer-deux model made by becruily. Also, all sound effects volumes are normalized to a maximum of -6dB.

You can check the [wiki](https://github.com/minhtridotnet/neuro-sama-soundboard/wiki/) page, where you can find stuff like browser support.

I'll add more sound effects in the future.

Thank you!
